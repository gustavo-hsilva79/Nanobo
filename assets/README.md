# Assets

Organização dos recursos do jogo.

- `sprites/`: personagens, agentes, animações e elementos visuais.
- `backgrounds/`: cenários e planos de fundo.
- `audio/music/`: músicas.
- `audio/sfx/`: efeitos sonoros.
- `fonts/`: fontes usadas pelo jogo.
- `data/`: dados auxiliares e arquivos carregados pelo jogo.
